# 大哉孔子

## 展览定位

1. 展览标题以“大哉”定位是表示孔子对于中国的意义重大。
2. 展览力图展现的是生活在春秋时期的孔子。
3. 展览要去除孔子在历史上被“神圣化”的部分，还原其人性。
4. 展览尽量不做主观评价，把想象空间留给观众。
5. 展览以“瞻之在前，忽焉在后”的主题思路去展示孔子思想。
