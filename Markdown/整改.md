# “大哉孔子”展整改工作汇报

## 意识形态把控

1. 《习近平在纪念孔子诞辰2565周年国际学术研讨会讲话》中指出”**研究孔子、研究儒学，是认识中国人的民族特性、认识当今中国人精神世界历史来由的一个重要途径。**“
2. 习近平在《把中国文明历史研究引向深入，增强历史自觉坚定文化自信》中指出“**我们坚持把马克思主义基本原理同中国具体实际相结合、同中华优秀传统文化相结合，不断推进马克思主义中国化时代化，推动了中华优秀传统文化创造性转化、创新性发展。要坚持守正创新，推动中华优秀传统文化同社会主义社会相适应，展示中华民族的独特精神标识，更好构筑中国精神、中国价值、中国力量。**”
3. 马克思在《关于费尔巴哈的提纲》中提出“**在其现实性上，它是一切社会关系的总和。**“

## 展览主题确定

1. 考察全国近年来以孔子主题的展览，结合我们对来馆观众的调查问卷，策展团队认为要**先做减法，再做加法**。
2. 多角度、多层次地去展现一个生活在春秋时期的孔子作为”人“的一面，引发观众对于孔子的兴趣并形成评价。
3. ”大哉孔子“取自《论语》，这是孔子同时期的人对孔子的评价：**孔子拥有不平凡的人生，展现了人性的光辉**。
4. 基本评价：**孔子是我国古代重要的思想家、教育家，儒家学派的创始人，他的学说是中国传统文化的主流，他的思想对世界产生了深远影响。**

## 展览内容解析

1. 礼乐文化是中华文明的重要源泉，鲁国的特殊地位保存了上古文明成果。
2. 以孔子秉承仁者爱人的情怀去实现改善社会的理想为主线，串联他的一生。
3. 分析孔子思想的最高目标、核心内容、外在表现和实现路径，完成逻辑上的闭环。
4. 从中国和世界两个方面客观看待孔子及其思想的影响。

## 展览亮点展示

1. 展览消解孔子被后世所赋予的神圣光环，还原了一个饱经忧患但矢志不渝的积极实践者。
2. 展览正视了与孔子强相关文物匮乏的现实问题，将展览重心放在生平和思想部分，讲好孔子的故事。
3. 展览立足《论语》和《史记·孔子世家》，将对话和故事进行多媒体展示。
4. 展览的形式设计突出流动感、对话感、故事感和参与感。
